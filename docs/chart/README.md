# The stories chart — generated artefacts

Everything in this directory is generated by `npm run chart` and committed so the docs
site and the README have something to point at. **Do not edit these files by hand**;
edit the code, regenerate, and commit the diff.

| file | what it is |
|---|---|
| `chart.json` | the spec — the single input all three renderers consume |
| `timeline.svg` | inert SVG, theme-aware via CSS variables + `prefers-color-scheme` |
| `timeline.png` / `timeline-dark.png` | 2000 px raster copies for contexts that strip SVG and JS (README, npm, chat, slides) |
| `timeline.html` | the interactive view: pan, zoom, keyboard, URL and `#universe-id` links |
| `timeline.js` | that interaction — vanilla ES2020, no framework, no network |

## What "default view" means

The chart is the library's front door (james-gibson/local-time#228): one point per work,
x at its publication date, y at how far the setting sits from that date, with the cone
marking where the reader's present has overtaken a work's own claim. Chart form after
xkcd #1491, *Stories of the Past and Future* (Randall Munroe, CC BY-NC 2.5) —
<https://xkcd.com/1491/>. The form is reused; the artwork is not, and is not vendored.

## Commands

```sh
npm run chart                # the corpus, drawn for the current year
npm run chart:authority      # the xkcd #1491 fixture, drawn for 2015 (its own now)
npm run chart -- --now 2030  # an explicit reader origin; recorded in the spec and on the image
npm run chart:console         # the console view, same spec
```

`--now` is not decoration. The chart's classes are a property of *(work, reader)*, not of
the work: the same entry is "still possible" in 1970 and "obsolete" in 2026. The committed
artefacts state the origin they were drawn for, in the image and in `chart.json`, so a
screenshot cannot pass as a differently-dated chart.

## Where the docs site picks it up

`personal/docs` publishes with `npm run publish` (`lore && build && verify-publish`), and
its `scripts/lore-content.mjs` already pulls content out of this repo. The chart joins
that seam rather than adding a second one: copy `docs/chart/**` into the site's static
assets during the `lore` step, and have `verify-publish.mjs` fail when the chart is missing
or its spec hash is stale. Until that lands, the site can embed `timeline.svg` directly.

## Determinism

`chart.json` and `timeline.svg` are byte-identical for the same input and the same
`--now`. The PNGs are byte-identical for the same input, `--now`, and font set — the
raster path uses the system font database through `@resvg/resvg-js`, which is the price
of rendering text without vendoring a font. That is why the SVG, not the PNG, is the
artefact to diff.
